# python-money-tracker-cli

hi! this is my simple python script for track how much money i spend in terminal.
sory if code is little messy, i am still learning python file handling and json.

## what it can do
- add expense with category, amount, note and time
- set your budget
- show how much you spend per category and how much money left
- export to csv file or monthly json summary

## how to use
```bash
python tracker.py budget 600
python tracker.py add 12.50 food --note "lunch sandwich"
python tracker.py summary
